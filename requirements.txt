# Student Master Application - System Requirements

## Flutter SDK
Flutter 3.9.2 or higher
Dart 3.0.0 or higher

## Platform-Specific Requirements

### iOS Development
- macOS with Xcode 14.0 or higher
- CocoaPods 1.11.0 or higher
- iOS 12.0 or higher target

### Android Development
- Android Studio 2022.1.1 or higher
- Android SDK 21 or higher (Android 5.0 Lollipop)
- Gradle 7.5 or higher

### macOS Desktop
- macOS 10.14 (Mojave) or higher
- Xcode Command Line Tools

### Windows Desktop
- Windows 10 or higher
- Visual Studio 2022 with C++ development tools

### Linux Desktop
- Ubuntu 20.04 LTS or higher (or equivalent)
- GTK 3.0 development libraries
- Clang 10.0 or higher

## Installation

1. Install Flutter SDK from https://flutter.dev/docs/get-started/install
2. Verify installation: `flutter doctor`
3. Navigate to src/ directory: `cd src`
4. Install dependencies: `flutter pub get`
5. Run the app: `flutter run`
